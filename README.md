# RougeLike

## 環境

Unity 2021.3.22f1

## 基本的な操作

- WASD もしくは十字キーでプレイヤーの移動・カーソルの移動。
- Shift キーを押しながらの状態で移動はせずに向きだけ変える。
- Enter キーが決定で、Tab キーがキャンセルボタン。
- Esc キーでメニューの開閉(現状はメニューがあまり意味をなしていない)
- Space キーでその場待機
- 1,2,3,4 キーで手札を使用
- ショップ画面でのみ、Q/E でタブ切り替えが可能。

## 実装済みのカードについて

1. 弱攻撃・強攻撃
   - 敵が隣接しているか、同じ部屋に敵がいる場合に使用可能
   - 自分が向いている方向にいる敵に攻撃をする
   - 向いている方向に敵がいなければ不発する
2. 範囲攻撃
   - 敵が攻撃範囲内(自分の周囲 8 マス)か、同じ部屋に敵がいる場合に使用可能
   - 自分の周囲 8 マスに攻撃を行う
3. 全体攻撃
   - 敵が隣接しているか、同じ部屋に敵がいる場合に使用可能
   - 同じ部屋にいる敵全員に攻撃を行う。
   - 自分が部屋にいない場合は隣接する敵に対して攻撃を行う
4. 遠距離攻撃
   - 敵が攻撃範囲内(直線上にいる)にいるか、同じ部屋に敵がいる場合に使用可能
   - 自分が向いている方向に射程 10 マスで矢を飛ばして、一番最初に当たった時点でダメージを与える
5. リソースアタック
   - 弱攻撃とほぼ同じだが、この攻撃で倒した場合にのみ必ずお金をドロップする
6. おにぎり
   - 自分のスタミナが減っている場合にのみ使用でき、スタミナを 50 回復する
7. 薬草
   - 自分の HP が減っている場合にのみ使用でき、HP を 30 回復する
8. チャージ
   - いつでも使用可能
   - 自分の次の攻撃のダメージを 2 倍にし、連続して使用することで 3 倍・4 倍と上昇する。
   - ただし最大で 4 倍までで、一歩でも動くと効果が切れる
9. 貫通の矢
   - 敵が直線上にいるか、隣接している場合に使用可能
   - 自分が向いている方向に射程 10 マスの矢を放ち、直線上の敵全てを貫通してダメージを与える
10. 毒刃
    - 敵が隣接している場合に使用可能
    - 前方の敵にダメージを与え、倒せなかった場合は毒(毎ターンダメージ)を付与する
11. 麻痺の針
    - 敵が隣接している場合に使用可能
    - 前方の敵にダメージを与え、倒せなかった場合は麻痺(行動不可)を付与する
12. 拘束の鎖
    - 敵が隣接している場合に使用可能
    - 前方の敵にダメージを与え、倒せなかった場合は拘束(移動不可)を付与する
13. 解毒薬
    - 自分が状態異常の場合にのみ使用でき、状態異常をすべて回復する
14. 引き直し
    - 自分以外の手札が 1 枚以上ある場合に使用可能
    - 手札をすべて捨てて、デッキから同じ枚数引き直す(デッキが空の場合は墓地をシャッフルして山札に戻す)
15. すり替え
    - 敵が隣接している場合に使用可能
    - 前方の敵と自分の位置を入れ替える(移動扱いのためチャージは切れる)
16. ノックバック
    - 敵が隣接している場合に使用可能
    - 前方の敵にダメージを与えて 3 マス吹き飛ばす。壁や他の敵に激突した場合は追加ダメージ
17. フックショット
    - 敵が直線上にいるか、隣接している場合に使用可能
    - 直線上の敵を自分の目の前まで引き寄せてダメージを与える
18. 追い討ち
    - 敵が隣接している場合に使用可能(通常攻撃と同じ条件)
    - 前方の敵に弱攻撃より少し弱いダメージを与える。対象が状態異常なら 3 倍のダメージ
19. 地雷設置
    - 足元に罠がなく、階段の上でない場合に使用可能
    - 自分の足元に地雷を設置する(敵だけでなく自分も踏むと発動する)
20. 切り札
    - 手札がこのカード 1 枚だけで、敵が隣接している場合に使用可能
    - 前方の敵に 50 ダメージ
21. 感染
    - 敵が隣接している場合に使用可能
    - 前方の敵にダメージを与え、その敵にかかっている状態異常を同じ部屋の敵全員にうつす(倒しても感染する)
22. 吸血の牙
    - 敵が隣接している場合に使用可能
    - 前方の敵にダメージを与え、与えたダメージの 50%の HP を回復する
23. 煙玉
    - 敵が隣接しているか、同じ部屋に敵がいる場合に使用可能
    - 同じ部屋の敵全員に 3 ターンの盲目を与えて自分を見失わせる(盲目中の敵はプレイヤーを再発見できないが、隣接されると攻撃は受ける)

## 実装済みの敵について

敵の行動パターンはマスタデータ(MEnemy)の aiType で指定する。
不思議のダンジョンシリーズの定番の敵をモチーフにしている。

1. カプセル Lv1 / Lv2(通常型 / マムル相当)
   - プレイヤーを発見するまでは部屋から部屋へ巡回し、発見後は接近して隣接攻撃を行う
2. ミニキャノン(遠距離型 / コドモ戦車相当)
   - プレイヤーが直線上(8 方向・射程 5 マス)にいて、間に壁や他ユニットがなければ弾を撃つ
   - 隣接時は通常攻撃を行う
3. 毒ダケ(状態異常投擲型 / おばけ大根相当)
   - プレイヤーと同じ部屋にいる場合、毒(3 ターン・毎ターン 3 ダメージ)を投げつける
   - プレイヤーが毒状態の間は投げず、接近して通常攻撃を行う
4. 盗賊モグラ(盗み型 / ガマラ相当)
   - 隣接時に攻撃の代わりにジェムを盗み(最大 300)、盗んだ後はプレイヤーから逃げ回る
   - 倒すと盗まれたジェムをその場にドロップする
   - プレイヤーがジェムを持っていない場合は通常攻撃を行う
5. 分裂スライム(分裂型 / ミドロ相当)
   - ダメージを受けて生き残った場合、40%の確率で空いている隣接マスに分裂する
   - 分裂した個体は現在の HP を引き継ぐ
6. 疾風ウサギ(倍速型 / ちゅうチンタラ相当)
   - 1 ターンに 2 回行動する(移動 2 回、または移動+攻撃、攻撃 2 回)
7. いねむりゴーレム(居眠り型)
   - プレイヤーが同じ部屋に入るか隣接するまでその場から一切動かない
   - ステータスが高いため、起こさずにやり過ごすこともできる
8. カマイタチ(手札落とし型 / ケンゴウ相当)
   - 攻撃を当てると、プレイヤーの手札からランダムに 1 枚を捨て札に送る
   - 捨てられた分は山札から即座に引き直されるが、手札のパッシブカードも容赦なく落とされる

## 状態異常について

- 敵に付与できる状態異常: 毒(毎ターンダメージ)・麻痺(行動不可)・拘束(移動不可)
- 敵の状態異常は敵ターン終了時に経過処理され、指定ターン数で自然回復する
- プレイヤーの状態異常は解毒薬で回復できる

## 実装済みパッシブカードについて

手札に入っている間だけ効果を発揮するカード。
使用した場合はコストを支払い、破棄する(足りなくても破棄できる)

1. 皮の盾
   - 受けるダメージを 1 軽減
2. 割合防御
   - 受けるダメージを半減
3. 鉄の剣
   - 与えるダメージを 1 増加
4. 割合ダメージ UP
   - 与えるダメージを 50%増加
5. お金ドロップ UP
   - 敵を倒した際に 50%の確率でお金を落とすようになる
6. トゲの盾
   - 敵の攻撃に対して反撃を行い、1 ダメージ与える
7. カウンター
   - 敵の攻撃に対して反撃を行い、受けたダメージの半分を与える
8. 満足感
   - 毎ターン減少するスタミナの量を半減する
9. 千里眼
   - 敵の位置が常にミニマップに表示される
10. 罠師の腕輪
    - 罠を踏んでも発動しない(未発見の罠は踏むと位置だけ明らかになる。敵は通常通り罠にかかる)
